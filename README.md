# 🏎️ Porsche Analytics Dashboard

Dashboard interativa em HTML (arquivo único) construída a partir de uma planilha de vendas da Porsche, gerada com apoio de IA e publicada no GitHub Pages. Projeto desenvolvido para o desafio do curso **Criando Agentes de Tratamento de Dados** da [DIO](https://www.dio.me/).

> A ideia central: transformar uma planilha estática em uma dashboard que responde **perguntas de negócio**, com filtros, indicadores e link próprio, sem as limitações do Excel.
